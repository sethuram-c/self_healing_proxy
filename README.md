# Self-Healing Edge-Aware Micro-Proxy

A Linux-native reverse proxy and observability engine
implemented using C and Python.

## Architecture

- C11 event-driven networking core
- Linux epoll
- Linux namespaces and cgroups v2
- Python orchestration and recovery
- OpenTelemetry observability
- Edge-aware backend routing

## Development Environment

- Fedora Linux
- GCC and Make
- Python 3
- Git

## Build

make

## Run

make run

## Test

make test

## Sanitizer Check

make sanitize
